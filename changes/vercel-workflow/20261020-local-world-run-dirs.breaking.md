`LocalWorld` now stores event and step files one directory per run (`events/<runId>/`, `steps/<runId>/`), matching `@workflow/world-local`, so reading a run lists only that run's files. Local run data is not migrated: a data directory with `.json` files directly under `events/` or `steps/`, such as one written by an older version, raises `DataDirLayoutError` and is left untouched. Delete it (by default `.workflow-data`) to start fresh. Inspect runs with `workflow` CLI 5.2.0 or later.
