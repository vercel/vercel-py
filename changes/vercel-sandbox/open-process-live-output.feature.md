Add `open_process`, a scoped alternative to `run_process` that routes output while the process is still running. Entering the block yields a handle with the process ID immediately, so callers can record it or wait for readiness before the process exits. Leaving the block normally waits for exit and applies `check`; leaving it through an exception closes the stream without killing the process. The synchronous handle owns no thread: it is iterable, and output is read only as the caller iterates or calls `wait()`.
