Replace all Sandbox dataclass records and public user handles with Pydantic v2 models, including network policies, process results, directory entries, mounts, snapshot expiration and retention state, routes, credentials, and service options. Use Pydantic validation and serialization methods instead of dataclass utilities; invalid fields and frozen-field assignments now raise `pydantic.ValidationError`. Most model constructors now require keyword arguments; positional snapshot expiration, mount, matcher, and credentials constructors remain supported.

Internal state, pagination records, deferred request parameters, upload metadata, terminal frames, recovery attempts, and output targets also use Pydantic. State attached to `SandboxResponseError.data` is now a model. Recovery and output models remain mutable and retain live runtime references. Deferred asynchronous create, fork, and resume parameters validate when the operation is constructed. Network policies still require a `NetworkPolicy` instance.
