Run `fs.exists()`, `fs.is_file()`, `fs.is_dir()`, `fs.listdir()`, `fs.remove()`, and `fs.rename()` in one request instead of three, which more than halves the time each call takes. `fs.remove()` and `fs.rename()` can no longer run twice: starting them is not retried after a transient failure, and a sandbox that stops while one is running is not resumed to run it again. The read-only checks still retry a failed start, but a sandbox that stops while one is running now raises `SandboxStreamError` instead of being resumed, as `run_command()` does.
