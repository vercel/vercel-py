Support process standard input: `create_process(stdin=subprocess.PIPE)` exposes `process.stdin` as an `anyio.abc.ByteSendStream` (a writable `io.RawIOBase` in the sync API), `communicate(input)` writes and closes it, `run_process(input=...)` feeds a process it waits on, and processes from `get_process` and `query_processes` can write to the stdin of a process started elsewhere. User handles take the same options. Writes are delivered in order and retried without duplicating input, so stdio servers such as MCP servers can run inside a sandbox.
