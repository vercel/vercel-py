`vercel.sandbox` is now the promoted Sandbox API that previously lived at
`vercel.unstable.sandbox`. The former `vercel.sandbox` surface, including
`AsyncSandbox`, `Command`, `AsyncCommand`, and `TokenProvider`, is gone, and
`vercel.unstable` has been removed. Use `vercel.sandbox` for the async API and
`vercel.sandbox.sync` for the synchronous API.

The Sandbox implementation now ships in the separate `vercel-sandbox`
distribution, which `vercel` depends on, so `vercel.sandbox` imports keep
working without installing anything extra.
