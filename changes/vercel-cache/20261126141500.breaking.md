Hash Runtime Cache keys with SHA-256 by default instead of a 32-bit djb2 hash, which caused distinct keys to collide and overwrite each other's values at scale.

Every key hashed with the default function changes, so entries written by earlier versions miss once after upgrading and are repopulated. Keys passed through a custom `key_hash_function` are unaffected. The new default matches `@vercel/functions`, so Python and JavaScript continue to share cache keys once both are upgraded.
