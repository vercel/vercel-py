Add `vercel-passport`, a Python port of `@vercel/passport` for reading and verifying Vercel Passport visitor identities.

`get_identity` reads the current request's Passport identity and verifies it, including sessions split across several cookies, with a synthesized identity for local development. Unverified debugging tokens are accepted only in local development unless `allow_unverified=True` is passed. `require_identity` does the same but raises unless there is an identity with a token. `verify_identity` verifies a Passport token forwarded from another app. All three are available from `vercel.passport` (async) and `vercel.passport.sync`.
