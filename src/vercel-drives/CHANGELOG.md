# Changelog

## 0.1.0 - 2026-11-20

### Features

- Add `vercel-drives`, a Python SDK for Vercel Drives. `vercel.drives` and its
  `vercel.drives.sync` mirror provide `get_drive`, `get_or_create_drive`,
  `fork_drive`, `delete_drive`, and `query_drives`, the `Drive` and `SyncDrive`
  handles, and the `DriveMount` values that `vercel-sandbox` mounts. (#557)
